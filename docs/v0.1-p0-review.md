## Resource and rollback boundary

The verifier is stateless and offline. The fixed Node 20 bundle, bounded inputs, and test matrix are the resource boundary. Rollback is an immutable version pin change; no database or receipt ledger exists.

## Efficiency decisions

| Improvement | Current cost | Expected benefit | Validation |
| --- | --- | --- | --- |
| One canonical policy pass after adapter normalization | zero model/API calls; one bounded trace traversal | avoids duplicate adapter-specific policy work and keeps runtime linear in trace size | F/I equivalence and 74-test suite |
| Bounded input sizes and event count | at most 20 MiB trace, 50,000 events, 256 KiB/line | prevents unbounded CPU/memory work on hostile evidence | F22/I14 size negatives |
| Shared fixtures and deterministic matrix helpers | one local run, no network | reduces repeated setup and makes failures reproducible | `pnpm test` 74/74 pass |
| Parse optional manifest sections once | one parse per optional section | avoids repeated YAML parsing and reduces rework risk | `pnpm exec tsc --noEmit` and manifest policy tests |
