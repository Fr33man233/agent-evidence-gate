# AEG v0.2.0 外部试点协议

**用途：** 供不参与实现的外部维护者在独立环境中执行；本文本身不是外部试点证据。  
**范围：** 仅验证 v0.2.0 的本地、离线、E1 gate 体验，不验证 E2 或生产 CI 身份。

## 参与者与环境

- 参与者必须不是本版本实现者，并在自己的干净 checkout、Node 24 和固定 lockfile 环境中运行。
- 不提供 secrets、个人数据、私有仓库或真实 agent 输出；只使用仓库内 sanitized fixture 和临时 Git 仓库。
- 参与者记录 OS、Node、pnpm、候选 commit、命令、耗时、退出码和 bundle SHA-256。

## 三态验收

1. **Fresh pass：** 用 synthetic native Receipt、`aeg-task/v2`、`aeg-trace/v1` 和临时 Git workspace 执行 CLI/Action，报告为 `pass`、`E1`、`local`。
2. **Expired fail：** 只修改 Receipt scope 中的覆盖文件，重复验证必须以 `AEG003` 失败，且不泄露文件内容。
3. **Rerun pass：** 重新采集 workspace fingerprint 并更新合成 Receipt core digest，重复验证再次 `pass`。

## 安全和隐私检查

- 在 manifest/trace/Receipt 中放入 privacy sentinel，确认 sentinel 不出现在 stdout、stderr、JSON、Markdown 或错误文本。
- 使用祖先 junction/symlink、scope escape、重复 key、未知 schema 和删除的 `--evidence` 参数，确认均失败封闭。
- 确认 verifier 不执行 Receipt command、candidate package/test/script，不访问网络或 secrets。

## 交付证据

外部试点必须返回一份不含私有数据的报告，至少包含参与者身份或组织、独立 checkout commit、环境、命令、原始退出码、三态结果、隐私检查结果、发现和建议。报告由参与者保存并经其确认；实现者不得代写“外部通过”结论。

## 当前状态

本地三态 pilot 已通过，但尚无独立外部参与者报告；因此外部试点门槛仍为 **未满足**。
