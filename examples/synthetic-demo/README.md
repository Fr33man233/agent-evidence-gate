# Synthetic demo

These files are deliberately fake and contain no project source, prompts, credentials, or real repository metadata. They show the smallest structured input shape used by the adapters and policy engine. The `head_sha` is a placeholder; a real invocation must use the current Git HEAD and its compatibility fingerprint, as demonstrated by `tests/cli-integration.test.ts`.

The demo is suitable for offline parser/policy experiments only. It is not evidence of real CI/E2 assurance.
